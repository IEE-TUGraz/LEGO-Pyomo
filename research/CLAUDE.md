# CLAUDE.md

This file provides guidance to Claude Code when working on research scripts.

## Overview

Research scripts are kept separate from the main codebase. Each subfolder focuses on a specific research topic and has its own `README.md` (usage/parameters for humans) and `CLAUDE.md` (non-obvious patterns for Claude).

- **`TR/`** — Network technical representation experiments: [`README`](TR/README.md) · [`CLAUDE`](TR/CLAUDE.md)
- **`MK/`** — Markov chain edge-handling experiments: [`README`](MK/README.md) · [`CLAUDE`](MK/CLAUDE.md)
- **`ID/`** — Inflow data aggregation experiments: [`README`](ID/README.md) · [`CLAUDE`](ID/CLAUDE.md)
